Chapitre 1 : Introduction et Connexion

1.1. Objectif de l'Application

L'application PackingList Pro est votre outil centralisé pour optimiser et tracer l'ensemble du processus de préparation de vos expéditions. Elle vous aide à gérer efficacement les listes de colisage (Packing Lists), les palettes, et à assurer un suivi précis des colis scannés. Grâce à son fonctionnement multi-sites, chaque entité opérationnelle peut gérer ses flux de manière indépendante tout en bénéficiant d'une plateforme unifiée.

Les objectifs principaux sont :

  • Rationaliser la préparation des expéditions.
  • Garantir une traçabilité complète des palettes et des colis.
  • Offrir une visibilité en temps réel sur l'avancement du colisage.
  • Comparer les quantités réellement scannées avec les prévisions théoriques.
  • Fournir des indicateurs de performance pour l'amélioration continue.

1.2. Accès et Connexion

Pour utiliser PackingList Pro :

  1. Ouvrez votre navigateur web (Chrome, Firefox, Edge, etc.).
  2. Entrez l'adresse URL de l'application qui vous a été communiquée (par exemple : http://votre-serveur.com/packinglist/public/).
  3. La page de connexion s'affiche. Saisissez votre nom d'utilisateur et votre mot de passe dans les champs prévus.
  4. Cliquez sur le bouton "Se connecter".

Si vous avez oublié vos identifiants ou rencontrez des problèmes de connexion, veuillez contacter votre superviseur ou l'administrateur de l'application.

Une fois connecté avec succès, vous serez dirigé vers votre Tableau de Bord personnalisé.

1.3. Rôles Utilisateurs

Votre accès aux différentes fonctionnalités de PackingList Pro dépend de votre rôle. Les principaux rôles sont :

  • Opérateur de Scan : Votre mission principale est sur le terrain. Vous utilisez l'application pour :
    • Activer les palettes avant de commencer le scan.
    • Scanner les QR codes des colis pour les enregistrer sur la palette active.
    • Visualiser la progression du remplissage de la palette active.
    Votre accès aux autres sections (création de Packing Lists, administration) est généralement limité.
  • Superviseur : Vous avez une vue d'ensemble des opérations de votre site. Vos responsabilités incluent :
    • Créer, gérer et suivre les Packing Lists pour votre site.
    • Générer et gérer les palettes.
    • Suivre les performances de scan et les écarts par rapport aux prévisions théoriques.
    • Potentiellement importer les fichiers d'expédition théorique.
    • Vous pouvez avoir des droits pour gérer les utilisateurs de votre site.
  • Administrateur : Vous avez un accès complet à toutes les fonctionnalités de l'application sur tous les sites. Vos tâches comprennent :
    • La gestion des comptes utilisateurs, de leurs rôles et de leurs permissions.
    • La création et la gestion des sites opérationnels.
    • La configuration globale de l'application (ex: patrons de codification).
    • La supervision de toutes les activités et l'accès à tous les rapports et KPIs.

Les fonctionnalités décrites dans ce manuel peuvent donc être visibles ou non en fonction de votre rôle.

Chapitre 2 : Tableau de Bord

Le Tableau de Bord est votre page d'accueil personnalisée. Il est conçu pour vous donner un accès rapide aux informations et aux actions les plus importantes pour votre travail quotidien.

2.1. Informations Générales

En haut du tableau de bord, vous trouverez :

  • Un message de bienvenue avec votre nom.
  • La date et l'heure actuelles.
  • Un bouton d'accès rapide "Démarrer / Reprendre Scan" si vous avez la permission de scanner des colis.

2.2. Widgets pour Opérateurs

Si votre rôle est Opérateur de Scan (ou si vous avez les permissions correspondantes) :

  • Palette de Scan Active : Si une palette est déjà active pour votre session de scan, ses informations s'affichent :
    • Code de la Palette
    • Référence de la Packing List associée et Site
    • Progression : Nombre de colis scannés / Nombre maximal de colis attendus.
    • Un bouton "Continuer Scan" pour retourner directement à l'interface de scan avec cette palette.
    • Un bouton "Désactiver" pour libérer la palette active.
  • Si aucune palette n'est active, un bouton "Activer une palette" vous mènera à l'interface de scan pour en sélectionner une.

2.3. KPIs et Statistiques (pour Superviseurs et Administrateurs)

Cette section affiche des indicateurs clés de performance. Par défaut, les Superviseurs voient les statistiques de leur site de rattachement. Les Administrateurs globaux voient les statistiques de tous les sites, avec un filtre pour sélectionner un site spécifique.

  • Nombre de Packing Lists Ouvertes.
  • Nombre de Palettes Ouvertes.
  • Nombre de Colis Scannés Aujourd'hui.
  • Nombre de Packing Lists Fermées Aujourd'hui.
  • Nombre de Palettes Générées (en attente d'ouverture).

2.4. Tâches en Attente (pour Superviseurs et Administrateurs)

Ce widget met en évidence les actions prioritaires :

  • Packing Lists Ouvertes en Attente : Affiche les dernières Packing Lists qui sont encore ouvertes et nécessitent un traitement (préparation, scan, fermeture).
    • Un lien direct vers la Packing List concernée.
    • Indication du site et de la date d'expédition.
    • Un lien pour "Voir toutes les PL ouvertes" si la liste est longue.
  • Lien rapide pour "Vérifier les Écarts de Scan" (si vous avez la permission).

Chapitre 3 : Gestion des Packing Lists

Ce module est principalement utilisé par les Superviseurs et les Administrateurs. Une Packing List (PL) représente une expédition et regroupe les palettes et colis qui la composent. Chaque PL est rattachée à un site spécifique.

3.1. Visualiser la Liste des Packing Lists

Pour accéder à la liste des Packing Lists :

  1. Utilisez le lien "Packing Lists" dans la barre de navigation latérale (menu "Gestion Colisage").
  2. Vous verrez un tableau listant les Packing Lists. Si vous êtes Administrateur, vous pourrez voir les PL de tous les sites et utiliser un filtre pour sélectionner un site spécifique. Si vous êtes Superviseur rattaché à un site, vous ne verrez que les PL de votre site.

Le tableau affiche les informations suivantes pour chaque PL :

  • Référence : Le code unique de la PL. Cliquer dessus mène aux détails de la PL.
  • Site : Le site opérationnel auquel la PL est rattachée.
  • Date d'expédition : La date prévue pour l'envoi.
  • Statut : Ouverte (en cours de préparation) ou Fermée (préparation terminée).
  • Nb Palettes : Le nombre de palettes associées à cette PL.
  • Créée le : Date et heure de création de la PL.
  • Actions : Des boutons d'action en fonction de votre rôle et du statut de la PL (Voir, Modifier, Fermer/Réouvrir, Supprimer).

Le tableau est interactif : vous pouvez trier les colonnes en cliquant sur leurs en-têtes, utiliser le champ de recherche pour filtrer rapidement, et naviguer entre les pages de résultats.

3.2. Créer une Nouvelle Packing List

Si vous avez la permission packinglist_create :

  1. Sur la page de la liste des Packing Lists, cliquez sur le bouton Créer une Packing List.
  2. Le formulaire de création s'affiche :
    • Date d'expédition : Sélectionnez la date prévue pour l'expédition (par défaut, la date du jour). Ce champ est obligatoire.
    • Site pour la Packing List :
      • Si vous êtes Administrateur ou un utilisateur global, sélectionnez le site concerné dans la liste déroulante. Ce champ est obligatoire.
      • Si vous êtes rattaché à un seul site, ce site sera automatiquement sélectionné (et le champ pourrait ne pas être modifiable).
  3. Cliquez sur Créer la Packing List.

Une référence unique sera automatiquement générée pour la nouvelle PL (ex: PL-NOMDUSITE-20250525-001). La PL est initialement au statut "Ouverte". Vous serez redirigé vers la page de détail de cette nouvelle PL.

3.3. Voir les Détails d'une Packing List

Pour consulter les informations complètes d'une Packing List et gérer ses palettes :

  1. Depuis la liste des Packing Lists, cliquez sur la Référence de la PL souhaitée (si vous avez la permission packinglist_read_one).
  2. La page de détail s'affiche, montrant :
    • Les informations générales de la PL (Référence, Site, Date d'expédition, Statut, dates).
    • Les boutons d'actions possibles sur la PL (voir ci-dessous).
    • Une section listant toutes les palettes associées à cette PL.
    • Des boutons pour gérer les palettes (Générer Palette, Imprimer QR Codes).
    • Des boutons pour exporter la liste des colis de cette PL (XLSX, PDF).

Actions sur la Packing List (depuis sa page de détail) :

  • Modifier Date : (Si PL Ouverte et permission packinglist_update) Permet de changer la date d'expédition.
  • Fermer la PL : (Si PL Ouverte et permission packinglist_close)
    • Change le statut de la PL à "Fermée".
    • Toutes les palettes Ouvertes et **non vides** associées à cette PL sont automatiquement passées au statut "Fermée".
    • Toutes les palettes Générées (jamais ouvertes) et **vides** associées sont supprimées.
    • Une fois fermée, la PL ne peut plus être modifiée (sauf réouverture), et aucun colis/palette ne peut y être ajouté.
  • Réouvrir la PL : (Si PL Fermée et permission packinglist_reopen)
    • Change le statut de la PL à "Ouverte".
    • Les palettes qui avaient été fermées lors de la clôture de la PL restent "Fermées" et doivent être réouvertes individuellement si nécessaire.
  • Supprimer la PL : (Si PL Ouverte et permission packinglist_delete)
    • Conditions : La PL doit être Ouverte et ne doit pas contenir de palettes Ouvertes avec des colis, ni de palettes Fermées.
    • Les palettes Générées (vides) associées seront supprimées avec la PL.
    • Une PL Fermée ne peut généralement pas être supprimée physiquement.
    • Une confirmation vous sera demandée.

3.4. Modifier une Packing List

Si une Packing List est Ouverte et que vous avez la permission packinglist_update :

  1. Allez sur la page de détail de la PL.
  2. Cliquez sur le bouton Modifier Date.
  3. Le formulaire d'édition s'affiche. Vous pouvez y modifier la **Date d'expédition**.
  4. Les autres informations (Référence, Site, Statut) sont affichées mais non modifiables ici.
  5. Cliquez sur Mettre à jour la date d'expédition.

3.5. Exporter les Colis d'une Packing List

Depuis la page de détail d'une Packing List, si vous avez la permission (ex: packinglist_read_one ou des permissions d'export spécifiques) :

  1. Cliquez sur le bouton Exporter Colis.
  2. Un menu déroulant apparaît avec les options :
    • Format XLSX (Excel)
    • Format PDF
  3. Choisissez le format souhaité. Le fichier contenant tous les colis de cette Packing List (répartis sur ses différentes palettes) sera généré et téléchargé.

Chapitre 4 : Gestion des Palettes

Les palettes sont les unités physiques sur lesquelles les colis sont groupés. Elles sont toujours rattachées à une Packing List.

4.1. Générer une Palette

Pour créer une nouvelle palette, la Packing List parente doit être Ouverte et vous devez avoir la permission palette_create.

  1. Allez sur la page de détail de la Packing List concernée (/packing-lists/show/{id}).
  2. Dans la section "Palettes Associées", vous avez deux options :
    • Palette Unique : Cliquez sur le bouton Palette Unique. Une nouvelle palette est instantanément créée avec le statut "Générée". Un code unique et un QR code lui sont assignés.
    • Multi-Palettes : Cliquez sur le bouton Multi-Palettes. Une petite fenêtre (modale) s'ouvre. Entrez le nombre de palettes que vous souhaitez générer (ex: 5) et validez. Les palettes seront créées avec le statut "Générée".
  3. La liste des palettes sur la page de la Packing List est mise à jour.

4.2. Voir les Détails d'une Palette

Si vous avez la permission palette_read_details :

  1. Depuis la liste des palettes sur la page de détail d'une Packing List, cliquez sur le Code Palette souhaité.
  2. La page de détail de la palette (/palettes/show/{id}) s'affiche avec :
    • Les informations de la palette (Code, QR Code téléchargeable, PL parente, Site, Statut, Max Colis, Colis Scannés, dates).
    • Les actions possibles sur la palette (voir ci-dessous).
    • La liste de tous les colis scannés sur cette palette.
    • Un bouton pour "Scanner des Colis" si la palette est ouverte.

Formulaire d'Ouverture de Palette (si statut "Générée")

Si une palette est au statut "Générée", que sa Packing List parente est "Ouverte", et que vous avez la permission palette_open :

  • Un formulaire s'affiche sur la page de détail de la palette vous demandant de saisir le **"Nombre max de colis"** que cette palette peut contenir.
  • Entrez une valeur et cliquez sur "Ouvrir et Enregistrer Max Colis".
  • La palette passe au statut "Ouverte", et vous pouvez commencer à y scanner des colis.

Actions sur la Palette (depuis sa page de détail) :

  • Modifier Max Colis : (Si palette Ouverte et permission palette_update_max_colis)
    • Cliquez sur l'icône à côté de "Max Colis".
    • Une fenêtre (modale) s'ouvre. Entrez la nouvelle valeur maximale.
    • La nouvelle valeur doit être supérieure ou égale au nombre de colis déjà scannés sur la palette.
  • Fermer Palette : (Si palette Ouverte et permission palette_close)
    • Cliquez sur Fermer.
    • La palette passe au statut "Fermée". Aucun nouveau scan de colis n'est possible.
  • Réouvrir Palette : (Si palette Fermée, PL parente Ouverte, et permission palette_reopen)
    • Cliquez sur Réouvrir.
    • La palette repasse au statut "Ouverte". Le scan est à nouveau possible.
  • Supprimer Palette : (Si permission palette_delete et conditions remplies)
    • Conditions : La palette doit être soit "Générée" (et donc vide), soit "Ouverte" ET **vide** (aucun colis scanné).
    • Une palette "Fermée" ou "Ouverte" avec des colis ne peut pas être supprimée directement.

4.3. Imprimer les QR Codes des Palettes

Pour imprimer les étiquettes QR code pour une ou plusieurs palettes d'une Packing List (nécessite la permission palette_read_details ou une permission d'impression dédiée) :

  1. Allez sur la page de détail de la Packing List concernée.
  2. Dans la section "Palettes Associées", un tableau liste les palettes. Cochez la case à gauche des palettes dont vous voulez imprimer le QR code. Vous pouvez utiliser la case "Tout sélectionner" dans l'en-tête du tableau.
  3. Cliquez sur le bouton Imprimer QR.
  4. Une fenêtre (modale) "Imprimer les QR Codes des Palettes" s'ouvre. Vous pouvez y ajuster :
    • Largeur et Hauteur de l'étiquette (en mm).
    • Nombre de QR codes par ligne sur la page d'impression.
    • Taille du QR code lui-même sur l'étiquette (en mm).
    • Option pour inclure le code de la palette en texte sous le QR code.
  5. Cliquez sur Préparer l'impression.
  6. Une nouvelle page/onglet s'ouvre avec les QR codes des palettes sélectionnées, formatés selon vos spécifications.
  7. Utilisez la fonction d'impression de votre navigateur (Ctrl+P ou Cmd+P) pour imprimer cette page sur vos étiquettes. Assurez-vous que les paramètres de votre imprimante (taille du papier, marges "aucune" ou "minimales") correspondent à vos étiquettes.

L'application génère une page optimisée pour l'impression. L'ajustement final pour l'alignement sur les étiquettes physiques se fait via les paramètres du dialogue d'impression de votre navigateur et les réglages de votre imprimante d'étiquettes.

Chapitre 5 : Scan des Colis

Cette section est cruciale, en particulier pour les Opérateurs de Scan. Elle décrit comment enregistrer les colis sur les palettes en utilisant leurs QR codes.

5.1. Accéder à l'Interface de Scan

Si vous avez la permission colis_scan :

  • Vous pouvez accéder à l'interface de scan via le lien "Scan Colis" dans la barre de navigation latérale (menu "Gestion Colisage").
  • Ou, si vous êtes sur la page de détail d'une palette Ouverte, un bouton Scanner des Colis (ou similaire) vous y mènera directement, en activant cette palette pour le scan.

L'URL de cette interface est typiquement /colis/scan.

5.2. Étape 1 : Activer une Palette pour le Scan

Avant de pouvoir scanner des colis, vous devez indiquer à l'application sur quelle palette vous travaillez.

  1. Si vous n'êtes pas arrivé sur cette page via un lien direct depuis une palette spécifique, le curseur sera positionné dans le champ "Scanner ou saisir le code de la palette".
  2. Scannez le QR code de la palette physique que vous souhaitez utiliser. Le code de la palette devrait apparaître dans le champ.
  3. Alternativement, vous pouvez taper manuellement le code de la palette.
  4. Cliquez sur le bouton Activer Palette.

Résultat de l'Activation :

  • Palette Inexistante ou Fermée : Si le code scanné ne correspond à aucune palette ou si la palette est au statut "Fermée", un message d'erreur s'affichera, et vous devrez essayer un autre code.
  • Packing List Parente Fermée : Si la Packing List à laquelle appartient la palette est "Fermée", vous ne pourrez pas activer la palette pour le scan. Un message d'erreur vous l'indiquera.
  • Palette "Générée" (Premier Usage) :
    • Si la palette est au statut "Générée" (c'est-à-dire qu'elle vient d'être créée et n'a jamais été utilisée pour le scan), vous serez redirigé vers la page de détail de cette palette.
    • Sur cette page de détail, un formulaire vous demandera de saisir le "Nombre max de colis" que cette palette peut contenir.
    • Une fois le nombre max de colis enregistré, la palette passera au statut "Ouverte".
    • Vous devrez alors retourner à l'interface de scan (via le lien "Scanner des Colis" sur la page de la palette ou le menu) et ré-activer cette palette (qui sera maintenant ouverte).
  • Palette "Ouverte" (Succès) :
    • Si la palette est trouvée et est déjà au statut "Ouverte" (et que sa PL parente est aussi ouverte), un message de succès s'affichera : "Palette [CODE_PALETTE] activée pour le scan."
    • Une section "Palette Active" apparaîtra, affichant :
      • Le code de la palette active.
      • Son statut (Ouverte).
      • Le nombre maximal de colis défini.
      • Le nombre de colis déjà scannés sur cette palette.
      • La référence de la Packing List parente.
    • Le champ pour scanner les colis (voir Étape 2) devient disponible et le curseur s'y positionne automatiquement.

Si une palette est déjà active et que vous souhaitez en changer, vous pouvez cliquer sur le bouton Désactiver Palette Actuelle pour revenir à l'étape de sélection.

5.3. Étape 2 : Scanner les Colis

Une fois qu'une palette est active :

  1. Le curseur est positionné dans le champ "Scanner le QR code du colis ici...".
  2. Scannez le QR code imprimé sur l'étiquette du colis.
  3. Le contenu du QR code (qui est une chaîne de texte contenant plusieurs informations sur le colis, séparées par des `|` et des `;`) s'affiche dans le champ.
  4. L'application soumet automatiquement ce scan (généralement, votre lecteur de code-barres simule une pression sur la touche "Entrée" après le scan).

Traitement et Validation du Scan Colis :

L'application effectue plusieurs vérifications :

  • La palette active est toujours valide et ouverte.
  • Le format du QR code scanné est correct (peut être parsé en clé/valeur).
  • Le **Numéro de Colis** (`package_number`) extrait du QR code est présent.
  • La **capacité maximale** de la palette active n'est pas dépassée.
  • Le **Numéro de Colis** (`package_number`) n'a **pas déjà été scanné** auparavant dans toute l'application (il doit être unique).
  • La quantité dans le colis (si présente dans le QR) est valide.

Feedback du Scan :

  • En Cas de Succès :
    • Un message vert s'affiche brièvement : "Colis [NUMERO_COLIS] scanné et ajouté à la palette [CODE_PALETTE]."
    • Le colis est enregistré en base de données et lié à la palette active.
    • Le compteur "Colis Scannés" de la palette active est mis à jour.
    • La liste des "5 Derniers Colis Scannés sur cette Palette" (si affichée) est mise à jour.
    • Le champ de scan est vidé et le curseur s'y repositionne automatiquement, prêt pour le prochain scan.
  • En Cas d'Erreur :
    • Un message d'erreur rouge s'affiche, expliquant le problème (ex: "Palette pleine", "Numéro de colis déjà scanné : XYZ", "Format du QR code colis invalide").
    • Pour les erreurs critiques (palette pleine, colis doublon, format invalide), **le fond de l'écran entier devient rouge vif** pour alerter immédiatement l'opérateur.
    • Le contenu du QR code scanné (qui a causé l'erreur) reste affiché dans le champ de scan pour que l'opérateur puisse le voir.
    • L'interface reste sur la même palette active.
    • Le curseur revient au champ de scan.

Attention : Si l'écran devient rouge, arrêtez le scan, lisez attentivement le message d'erreur, et corrigez le problème (ex: prendre une nouvelle palette si pleine, vérifier si le colis n'a pas déjà été scanné par erreur) avant de continuer.

5.4. "Dé-scanner" un Colis (Retirer un Colis d'une Palette)

Cette action est généralement réservée aux Superviseurs ou Administrateurs et nécessite la permission colis_delete.

Si un colis a été scanné par erreur sur une palette :

  1. Allez sur la page de détail de la palette concernée (/palettes/show/{id}).
  2. Dans la liste "Colis sur cette Palette", localisez le colis à retirer.
  3. Si la palette est toujours Ouverte, un bouton (ou "Dé-scanner") sera visible à côté du colis.
  4. Cliquez sur ce bouton. Une demande de confirmation apparaîtra.
  5. Confirmez la suppression. Le colis sera retiré de la palette et de la base de données.

Un colis ne peut être dé-scanné que si sa palette est encore "Ouverte".

5.5. Regrouper des Colis (Parent/Enfants)

Dans certaines situations, plusieurs colis physiques sont liés entre eux (ex : un carton principal et des sous-colis). L'application permet de les regrouper en scannant d'abord un colis parent, puis ses colis enfants.

  1. Scannez un QR code contenant uniquement le champ package_number : un nouveau colis parent est créé sur la palette active.
  2. Tous les scans suivants sont enregistrés comme enfants tant que ce parent reste actif. Ils héritent du parent et n'occupent pas de place supplémentaire dans la capacité de la palette.
  3. Pour terminer le groupage, re-scannez le numéro du parent ou cliquez sur Terminer le groupage s'il est proposé.

Sur la page de détail d'une palette, les colis sont affichés avec leurs éventuels enfants pour une lecture plus claire.

5.6. Déplacer un Colis

Avec la permission colis_move, il est possible de transférer un colis (ou un groupe parent/enfants) vers une autre palette ouverte.

  1. Depuis la liste des colis d'une palette ouverte, cliquez sur l'icône à côté du colis.
  2. Indiquez le code de la palette de destination (qui doit être ouverte et différente de la palette source).
  3. Validez : le colis (et ses enfants éventuels) est déplacé vers la nouvelle palette.

5.7. Commenter un Colis

Les utilisateurs disposant de la permission colis_update_comment peuvent ajouter ou modifier un commentaire libre sur un colis depuis la page de la palette.

5.8. Recherche de Colis

Le menu "Recherche Colis" permet de retrouver un colis par numéro, SKU, OF, date de scan ou texte libre. Des filtres par site et statut de palette sont disponibles. Plusieurs termes peuvent être saisis dans la recherche libre, séparés par des espaces.

Chapitre 6 : Import Théorique et Suivi des Écarts

Ce module (permissions theoretical_import_csv et theoretical_view_deviations) vous permet de comparer les quantités de colis attendues avec celles réellement scannées.

6.1. Importer un Fichier Théorique

Le "théorique" représente les quantités d'articles (SKU) attendues pour chaque Ordre de Fabrication (OF) et Commande, pour un site et une semaine donnés.

  1. Accédez à "Importer Théorique" depuis le menu (ou le tableau de bord si Admin).
  2. Le formulaire d'import s'affiche :
    • Pour quel Site ? : Sélectionnez le site concerné par cet import.
    • Fichier CSV Théorique : Cliquez pour choisir le fichier CSV sur votre ordinateur. Le fichier doit contenir les colonnes : OF_NUMBER, ORDER_NUMBER, SKU, EXPECTED_QUANTITY. Le séparateur attendu est le point-virgule (`;`).
  3. Cliquez sur Importer et Remplacer Théorique Semaine.

Important : L'importation d'un nouveau fichier pour un site donné **écrasera toutes les données théoriques précédemment importées pour la semaine en cours** pour ce même site. La "semaine en cours" est déterminée par la date à laquelle vous effectuez l'import.

Après l'import, un message confirmera le nombre de lignes traitées. Si des erreurs sont détectées dans certaines lignes du fichier CSV (données manquantes, quantité invalide), ces lignes seront ignorées et un résumé des erreurs pourra être affiché.

6.2. Suivi des Écarts

Cette section vous permet de voir où se situent les différences entre ce qui était attendu (le théorique) et ce qui a été réellement scanné.

Accès aux Écarts :

  • Depuis une Packing List : Sur la page de détail d'une Packing List (/packing-lists/show/{id}), cliquez sur le bouton Voir Écarts. Cela affichera les écarts spécifiquement pour les colis de cette PL, en utilisant le théorique qui était actif pour le site de la PL et la semaine de sa date d'expédition.
  • Vue Globale des Écarts : Depuis le menu (ou tableau de bord), accédez à "Suivi des Écarts" (/theoretical-exports/deviations).

Interface de Suivi des Écarts :

La page affiche une série de filtres et un tableau de résultats :

  • Filtres :
    • Site : Obligatoire (sauf si vous venez d'une PL spécifique). Sélectionnez le site à analyser.
    • Année et Semaine : Sélectionnez l'année et le numéro de semaine (ISO) du théorique que vous souhaitez utiliser pour la comparaison. Par défaut, la semaine actuelle est proposée. Des boutons "< Sem. Préc." et "Sem. Suiv. >" permettent de naviguer.
    • N° OF, N° Commande, SKU : Filtres optionnels pour affiner la recherche.
    Cliquez sur Afficher pour lancer la comparaison.
  • Tableau des Résultats :
    • Colonnes : OF, Commande, SKU, Qté Attendue (théorique), Qté Scannée, Écart, Statut Écart.
    • Écart : `Scanné - Attendu`. Un nombre négatif indique un manquant, un positif un surplus.
    • Statut Écart et Couleurs :
      • COMPLET : Attendu = Scanné (et > 0).
      • MANQUANT : Scanné < Attendu.
      • MANQUANT TOTAL : Attendu > 0 mais Scanné = 0.
      • SURPLUS : Scanné > Attendu.
      • SCAN (NON ATT.) : Attendu = 0 mais Scanné > 0.
      • N/A : Attendu = 0 et Scanné = 0.
      Les lignes du tableau sont aussi colorées pour une identification rapide des problèmes.
    • Le tableau est interactif (tri, recherche dans les résultats, pagination).

Chapitre 7 : Administration

Ces fonctionnalités sont généralement réservées aux Administrateurs et parfois aux Superviseurs, en fonction des permissions qui leur sont attribuées. Elles sont accessibles depuis les liens dans la barre de navigation latérale.

7.1. Gestion des Utilisateurs (/users)

(Nécessite la permission user_manage)

  • Afficher la liste de tous les utilisateurs avec leur site de rattachement et leurs rôles.
  • Filtrer les utilisateurs par site.
  • Créer de nouveaux utilisateurs : définir nom d'utilisateur, email, mot de passe, prénom, nom, statut (actif/inactif), site de rattachement, et assigner des rôles.
  • Modifier les informations d'un utilisateur existant.
  • Désactiver ou Réactiver un compte utilisateur.
  • (Attention) Supprimer physiquement un utilisateur (généralement non recommandé, la désactivation est préférable).

7.2. Gestion des Rôles et Permissions

Gestion des Rôles (/roles)

(Nécessite la permission role_manage)

  • Afficher la liste de tous les rôles.
  • Créer un nouveau rôle (nom, description).
  • Modifier un rôle existant : changer son nom, sa description, et surtout **assigner ou retirer des permissions** à ce rôle via une liste de cases à cocher.
  • Supprimer un rôle (certains rôles système comme "Administrateur" peuvent être protégés contre la suppression).

Gestion des Permissions (/permissions)

(Nécessite la permission permission_manage)

  • Afficher la liste de toutes les permissions disponibles dans l'application.
  • Créer une nouvelle permission (nom/code unique et description). Cela est généralement fait par les développeurs lors de l'ajout de nouvelles fonctionnalités, mais l'interface existe.
  • Modifier la description d'une permission. Le nom/code n'est généralement pas modifiable car le code source s'y réfère.
  • Supprimer une permission (avec prudence, si elle n'est plus utilisée nulle part).

7.3. Gestion des Sites (/sites)

(Nécessite la permission site_manage)

  • Afficher la liste de tous les sites (actifs et inactifs).
  • Créer un nouveau site : définir un code unique, un nom, une adresse (optionnelle), et son statut (actif/inactif).
  • Modifier les informations d'un site existant.
  • Désactiver un site : Un site désactivé ne peut plus être sélectionné pour de nouvelles Packing Lists ou de nouveaux imports théoriques. Les données existantes liées à ce site sont conservées. La désactivation peut être empêchée si des Packing Lists ouvertes sont encore rattachées au site.
  • Réactiver un site précédemment désactivé.

7.4. Paramètres de l'Application (/settings)

(Nécessite la permission settings_manage)

  • Cette page permet de configurer des paramètres globaux de l'application.
  • Principalement, vous pouvez y définir les **patrons de codification** utilisés pour générer automatiquement :
    • Les références des Packing Lists (ex: PL-{SITE_CODE}-{YYYY}{MM}{DD}-{ID_PL}).
    • Les codes des Palettes (ex: PAL-{SITE_CODE}-{YYYY}{MM}-{COUNTER_MONTHLY_SITE_3DIGITS}).
    Une liste des placeholders disponibles (comme `{YYYY}`, `{MM}`, `{SITE_CODE}`, `{ID_PL}`, `{COUNTER_...}`) est fournie pour vous aider à construire ces patrons.
  • D'autres paramètres globaux pourraient être ajoutés ici à l'avenir.
